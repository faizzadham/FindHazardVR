# Convai Editor UI Style Guide

## Scope

This guide defines the shared IMGUI design system used by Convai SDK editor surfaces.

## Core Rules

- Use `ConvaiInspectorThemeTokens` for colors and spacing tokens.
- Use `ConvaiInspectorSectionChrome` for all collapsible section headers and bodies.
- Persist section state with `ConvaiInspectorSectionStateStore`.
- Resolve the Convai emblem via `ConvaiEditorIcons.Emblem()`.
- Do not allocate `GUIStyle` in per-frame draw paths. Cache styles in the editor host or use `ConvaiInspectorStyleCache`.

## Shared Controls

Reach for these before drawing a control by hand (all on `ConvaiEditorTheme`):

- `GhostButtonRow(a, b, c)`: a section's secondary actions, sized to their labels. A null slot is skipped.
- `FieldWithActions(...)`: a field with inline actions on its right (Copy beside an ID, Fetch beside a name).
  Put the reason a button is disabled in its tooltip.
- `LabeledSegments(label, options, index, property)`: a choice between two to four named options, such as
  Default / Custom. Show the fields a choice unlocks only when it is chosen, never greyed out.
- `CheckRow(...)` (or `ConvaiInspectorChecks.Row` from a `SetupHealthStatus`): one validation check.
- `GroupCaption(...)`: a named cluster inside a section. Runtime fields drawn by a custom inspector must not carry
  `[Header]`, which draws a second, unstyled title.

## Standard Header Layout

- Order: `icon -> chevron -> title`.
- Entire row is clickable for expand/collapse.
- Divider line is shown under expanded headers.
- Dark theme is the premium target.

## State Keys

Section keys are generated by:

`Convai.Editor.<EditorType>.<SectionId>.Expanded`

Examples:

- `Convai.Editor.ComponentEditor.CoreSetup.Expanded`
- `Convai.Editor.MapAssetEditor.Mappings.Expanded`

## How To Add A New Section

1. Define a stable section id constant in the host editor.
2. Load default state in `OnEnable`:
   `ConvaiInspectorSectionStateStore.Get(hostId, sectionId, defaultValue)`.
3. Save state in `OnDisable`:
   `ConvaiInspectorSectionStateStore.Set(hostId, sectionId, value)`.
4. Draw header using `ConvaiInspectorSectionChrome.DrawHeader`.
5. Draw body using:
   - `ConvaiInspectorSectionChrome.BeginBody(...)`
   - content
   - `ConvaiInspectorSectionChrome.EndBody()`

## Review Checklist

- No module-local duplicate design system helpers.
- No hardcoded editor icon file paths.
- No `EditorPrefs` ad-hoc keys for section state.
- No duplicated section header implementations.
- No per-frame style allocations in section frame paths.
