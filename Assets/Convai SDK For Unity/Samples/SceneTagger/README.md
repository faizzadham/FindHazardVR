# Scene Auto Tagger authoring sample

This sample walks through the authoring workflow using a generated fixture scene. Import it, then choose **Convai → Samples → Create Scene Tagger Fixture**. It creates a separate scene and material assets in a new `Assets/SceneTaggerFixture` folder. Existing open scenes stay open and are not saved by the generator.

Open Scene Auto Tagger, choose a configured account character, discover and analyze the fixture. Try the dark and metallic objects, the thin artwork panel, and the repeated exhibits. Enable **Re-analyze tagged objects** to check that the hand-authored description is preserved. Compare **Keep Separate**, **Nearby Clusters** and **Group All Verified** before Apply.

Correct a proposal, analyze it with notes, edit its view, use the new image, analyze again, Apply, and Undo. Standing positions require an existing baked NavMesh and are off by default. Add your configured Convai character and its existing gaze and movement setup when testing live description, looking and walking.

The fixture is an authoring exercise. Passing it does not qualify every material, pipeline, native platform or backend behavior.
